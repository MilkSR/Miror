# Content-signing public keys

These keys verify official Miror content releases. They are public by design: the same
keys ship in the app, and publishing them lets the source-available verifier authenticate
a release without access to Miror's private signing material.

Signing credentials are deliberately not part of the source-available publication. Never
add a private key to this document.
